# PPIP-Activity4

## Task Manager Application

This project is a Python-based task management application integrated with a GitHub Actions CI/CD pipeline.

## Features

- Create and manage tasks
- Track task status (ToDo and Done)
- Run automated unit tests
- Update index.html with task information and test results
- Build and run the application using Docker

## CI/CD Pipeline

GitHub Actions automatically builds the Docker image, runs the Python application and unit tests, and updates the HTML report.
